## 真实应用链路

另启动隔离的 PostgreSQL、FastAPI、nginx 与浏览器，唯一被替代的是 Amazon 采集边界。**页面数字为明确标注的模拟报告，不是真实店铺经营数据。**

1. 管理员配置三类数据源与 SKU 绑定后，后台调度自行创建并完成3个任务；没有手工调用 publish 或直接写入经营事实。
2. 自动获取的业务销售额为1400，SP归因销售为700、花费140，两者没有被加成2100；当前可售100，预留10未被重复扣除。
3. 管理员导入有效成本并设置补货周期，7日已结束业务日均速为10；无ETA在途40未充当可售，按MOQ/整箱规则给出120件补货建议。
4. 刷新后数据库结果保留；手机无外层横向溢出；JavaScript错误为0。
5. 完成后清理测试容器和测试库，主业务库未写入这些模拟指标。

## 未验证与剩余范围

- SP-API／Ads 真实应用准入、Refresh Token、账号授权和平台端报表结果尚未配置验证。凭据存在不代表已授权，更不代表同步成功。
- Ads 仅有 SP 商品粒度适配器；SB／SD／DSP、搜索词及广告位专项报告尚未接入。SP费率不能代替全渠道TACOS。
- 商品成本／头程等仍需CSV补充；退款、结算、实际税费和期间费用缺失时不计算真实净利润、回款或真实退货率。
- 模型为透明的历史均速、覆盖与成本基准；没有进行真实需求预测回测、广告增量实验或自动预算／采购执行。
- 当前模型延续单工作空间的账号权限，产品绑定稳定店铺；不是跨组织多租户隔离。既有授权环境前缀不能用于切换其他卖家身份。
- 未对用户个人 Mac 自动部署，也未在其浏览器验证本次版本。源码推送和 Codex 云端运行，与其他安装实例升级分开。
