# 全流程 SOP · 审批单

从全流程 SOP 点击一个事项，直接在当前上下文打开该产品的审批单。关闭后保留产品、搜索、筛选和滚动位置；流程协作中的卡片也打开同一审批单。

未发起时展示预设申请表和完整阶段，未录入的人员和日期显示“待分配”“未排期”。申请内容、模板定义和产品实际执行记录分别保存；模板升级不会替换已有实例。

## FCC 与其余事项

FCC 包含资料提交、负责人审批、认证机构接单与测试、草稿反馈、草稿审核与修订、正本签发与接收、最终验收与归档。FCC、危险品判定、标签确认各自是独立事项，并保留前置关系。008 迁移保留原综合任务 ID 和原记录，补充其余独立事项，不删除旧配置、证据、审批和文件。

各 SOP 按事项映射业务模板，使用对应工作对象、阶段字段、交付物与验收标准；自建事项使用所属专业模块的默认模板。覆盖明细可通过模板测试核验。

## 人员与操作

管理员负责配置申请表、步骤、处理人、审核人、协作人、计划和退回目标；个人角色名称和前端传入的身份不提供配置权。办理人与审核人分别指定，管理员身份不自动替代指定审核资格。

申请人保存和提交申请；指定办理人确认接单、填写结果并提交；指定审核人同意或退回。记录提交、接单、处理的真实登录身份和时间。外部机构人员可作为联系人登记，由内部经办人录入机构回执和实际事件日期，操作日志保留内部录入人身份。

退回到指定的修订环节，先前提交、文件和意见不被覆盖。已完成事项须由管理员说明原因重新打开。最终验收前，顶层 SOP 任务不会自动标为完成。

## 时间与附件

保留各阶段原计划开始／完成时间，同时记录最新预计、实际开始／完成、延误原因和下一步安排。计划调整保留前值、操作者、时间及说明，最新预计不替代原始计划。

附件关联具体产品事项、审批单及环节。支持文件上传和资料链接，标注版本；历史版本保留在当时提交快照中。实际收到草稿或正本的日期属于业务事件，录入时间及录入人由系统另外记录。

## 兼容与验证

旧的流程协作配置、提交、审核意见、证据和产品文件索引保留可查；所有事项（包括尚未发起的事项）均通过新审批链执行，旧写入接口已退役；旧接口不能绕过新流程推进任务。只读浏览可以查看预设要求，填写内容、流转记录与附件按登录权限提供。本版仍是单工作空间，不能把此功能表述为已实现跨组织数据隔离。

在独立测试数据库运行 `bash scripts/test_process.sh`，并运行前端规则检查。浏览器验收覆盖原 SOP 上下文、未发起详情、管理配置、多角色流转、退回修订、附件、刷新持久化和手机布局。实际执行结果与截图在交付中分别报告。

当前抄送节点记录站内流转，不代表已发送邮件或飞书消息。外部机构回执和文件仍需内部经办人登记，系统不自动签发或核验认证真实性。
